Project Overview

About This Library Chatbot Demo

This portal is a classroom demonstration site that simulates common library workflows and guided chat interactions.

What this demo includes

  • Home chatbot experience with suggested prompts.
  • Card Catalog browsing with filters and detail records.
  • Events calendar and recurring program highlights.
  • Program categories for Youth Services, Adult Services, Tech Team, and Special Collections.

Classroom use notes

  • Account pages are simulated and non-personalized.
  • Responses are designed for demonstration and practice scenarios.
  • Students can compare guided prompts with custom user questions.

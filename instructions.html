Instructions

How to use the library chatbot demo

  1. Start on the home page, where the chatbot opens with a welcome message.
  2. Select one of the quick-action prompts to simulate a common library question.
  3. Or type your own natural-language prompt about collections, events, programs, or reference help.
  4. Review the simulated response and continue the conversation as needed.

This demo is intentionally self-contained so it can be used in class without a live API connection.

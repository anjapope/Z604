Reference Services

Stapleton Public Library research help

Get SPL support with topic development, source discovery, citation practice, local history, and evaluating evidence. Pericles can retrieve and cite web sources for research questions when live search is available; availability of external sources is stated in each response.

Research support areas

  • Database navigation: Learn to search effectively and narrow results.
  • Citation guidance: Get help with MLA, APA, and source tracking.
  • Topic discovery: Build keywords and refine research questions.
  • Source evaluation: Compare credibility and relevance across sources.

Specialized help

  • Local history: Identify relevant archives, collections, and historical records.
  • Genealogy: Refine a family-history question and identify records that can help answer it.
  • Technology support: Use library tools for document and media projects.
